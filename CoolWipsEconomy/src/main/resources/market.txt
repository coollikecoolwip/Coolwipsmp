#
# Format:
# MATERIAL=FULL_PRICE_UNITS,STEP_UNITS,DROP_PERCENT,MIN_PRICE
#
# FULL_PRICE_UNITS = how many units can be sold each day at the normal/base price.
# STEP_UNITS = additional units sold before the next price drop.
# DROP_PERCENT = percentage removed at each step. 0.90 means the next tier is 10% of the previous tier.
# MIN_PRICE = hard minimum sell price for that item.
#
# Balance target:
# - Valuable renewable outputs get roughly $2,000 of full-price revenue.
# - Cheap bulk outputs are capped at 4,096 full-price units so ordinary players can still sell useful amounts.
# - Heavy grinders hit very steep diminishing returns, making additional volume worth little compared with normal volume.
# - MOSS_BLOCK specifically starts at $1.00 and bottoms out at $0.017.
